## Application Overview

**Application Name:** AAVA (AI-Assisted Knowledge Transfer Automation)

## Executive Summary

AAVA is an intelligent agent-based workflow system designed to automate the knowledge transfer process by converting meeting transcripts, presentations, and documents into structured knowledge base articles. The system performs gap analysis against existing documentation, generates coverage reports, and maintains version-controlled knowledge repositories.

**Key Capabilities:**
- Multi-format input processing (Transcripts, PPT, PDF, TXT, DOCX)
- Automated markdown generation and GitHub synchronization
- Intelligent gap analysis with similarity scoring
- Coverage metrics and risk assessment
- Follow-up question generation
- Consolidated KT document creation

---

## System Architecture

### Core Pipeline Workflow

The AAVA system implements a **4-agent workflow** architecture:

#### **Agent 1: Input Processing & MD Generation**
- **Function:** Accepts input files (transcript/PPT/document)
- **Output:** Converts content to structured Markdown (.md) format
- **Storage:** Uploads to GitHub repository

#### **Agent 2: Summarization**
- **Function:** Generates concise summary from input content
- **Output:** Summary markdown file
- **Storage:** Uploads summary to GitHub

#### **Agent 3: Repository Analysis & Matching**
- **Function:** 
  - Lists all directories in GitHub repository
  - Identifies domain-relevant files
  - Retrieves file content for matching documents
  - Calculates similarity scores
- **Output:** List of matching files with relevance scores

#### **Agent 4: Gap Analysis & Reporting**
- **Function:** 
  - Compares input content with existing repository files
  - Identifies coverage gaps
  - Generates comprehensive analysis report
- **Output:** Detailed gap analysis with recommendations
